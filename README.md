# ekeb-console-game
ЕКЕВ - консольная командная игра 
-Группа: Т118
О проекте:
ЕКЕВ - консольная игра, в которой игрок должен исправить 3 ошибки,используя подсказки,энергию и ходы
Команда:
-Шамсутдинова Карина - главное меню, игровой цикл, победа и проигрыш
-Райхерт Юлия - ошибки, загадки и проверка ответов 
-Бергело Виталий - зарядка, инвентарь и статус игрока 
-Тоқбас Алишер - обработка команд,неправильный ввод и тестирование 
Запуск 
Запустить файл :
-pyrhon game.py
Основные возможности :
-начало новой игры 
-просмотр правил
-осмотр стенда и получение подсказки
-получение и использование зарядки 
-исправление трёх ошибок 
-просмотр состояние игрока 
-победа после исправления всех ошибок 
-проигрыш при выполнении условий проигрыша
